# The line on a SwiftLink cartridge at $DE00, 9600 baud (run.sh with IFACE=swift): the settings
# choose it (key 1, pressed 2 time(s)) and PARLOR.CFG is written; the console talks to the modem stand-in;
# then P dials and signs up, and C=-Q closes the connection.
waittitle 6000
title 3600
waittext ParlorNet: connect 600
type S
waittext ParlorNet settings 300
type 1
wait 30
type 1
wait 30
snap swift_settings
key ret
waittext ParlorNet: connect 2400
snap swift_start
type C
waittext Line: 2400
type AT\r
waittext OK 300
snap swift_console
oa Q
waittext ParlorNet: connect 600
type P
waittext Name: 2400
snap swift_dialed
type new\r
waittext want 300
type sam\r
waittext password 600
type Swordfish 1997\r
waittext again 600
type Swordfish 1997\r
wait 600
snap swift_lobby
oa Q
waittext ParlorNet: connect 2400
snap swift_hungup
exit
