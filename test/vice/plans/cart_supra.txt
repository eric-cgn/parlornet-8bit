# The cartridge (parlornet.crt) with the Supra 2400 compatible modem on the user port at 2400 (run.sh with the
# cartridge as DISK, IFACE=user and BAUD=2400) and no drive: the title screen at once (cart_title), the
# settings as the cartridge starts them, SwiftLink compatible at $DF00 and kept for this session only
# (cart_settings); key 2 goes between $DF00 and $DF80, never $DE00, the cartridge's own (cart_addr); key 1
# makes the modem Supra 2400 compatible, at 2400 (cart_supra); then the console, the dialer, signing up, the
# lobby and Commodore-Q.
waittitle 600
snap cart_title
title 3600
waittext ParlorNet: connect 600
type S
waittext ParlorNet settings 300
wait 60
snap cart_settings
type 2
wait 30
snap cart_addr
type 2
wait 30
type 1
wait 30
snap cart_supra
key ret
waittext ParlorNet: connect 2400
snap cart_start
type C
waittext Line: 2400
type AT\r
waittext OK 300
snap cart_console
oa Q
waittext ParlorNet: connect 600
type P
waittext Name: 2400
snap cart_dialed
type new\r
waittext want 300
type cora\r
waittext password 600
type Swordfish 1997\r
waittext again 600
type Swordfish 1997\r
wait 900
snap cart_lobby
oa Q
waittext ParlorNet: connect 2400
snap cart_hungup
exit
