# The dialer on the WiFi-modem stand-in (port 16600; test/README.md), with the settings as they start:
# the init string ATZ, the number parlornet.org:6501 (the stand-in connects any number to
# the lab parlor). P sends ATZ, gets OK, dials ATDTparlornet.org:6501, and on CONNECT sends the opening at
# once and signs in. Open-Apple-Q closes the connection: the stand-in says NO CARRIER when the parlor hangs
# up, so no +++ is sent, and the start screen comes back, where P dials again.
wait 120
caps
title 1800
waittext ParlorNet: connect 1200
hold cfg_tutor 1 30
snap dial_start
dumptext dial_start
type S
waittext ParlorNet settings 300
snap dial_settings
dumptext dial_settings
key ret
waittext ParlorNet: connect 300
type P
waittext Name: 900
snap dial_dialed
dumptext dial_dialed
type new\r
waittext want 300
type dora\r
waittext password 600
type Swordfish 1997\r
waittext again 600
type Swordfish 1997\r
wait 600
snap dial_lobby
oa Q
waittext ParlorNet: connect 900
snap dial_hungup
type P
waittext Name: 900
type dora\r
waittext assword 600
type Swordfish 1997\r
wait 600
snap dial_lobby2
oa Q
waittext ParlorNet: connect 900
exit
