# The dialer's reset and init string, on the WiFi-modem stand-in (port 16600). With reset first off and
# the init string AT&F, P sends AT&F (OK) and dials, with no ATZ (modem.log shows the commands). An init
# string the modem answers with ERROR (the stand-in answers ERROR to a line that does not start with AT)
# stops the dial: "The modem says ERROR to X1." Then reset first on again, with the init string, dials too.
# Last, a number that starts with AT is the whole dial command: ATD"parlornet.org:6501", as for a Zimodem.
wait 120
caps
title 1800
waittext ParlorNet: connect 1200
type S
waittext ParlorNet settings 300
type 6
wait 30
type 7
wait 30
type AT&F\r
wait 60
snap di_settings
dumptext di_settings
key ret
waittext ParlorNet: connect 300
type P
waittext Name: 900
snap di_dialed
dumptext di_dialed
oa Q
waittext ParlorNet: connect 1200
type S
waittext ParlorNet settings 300
type 7
wait 30
arrows LLLL
type X1\r
wait 60
key ret
waittext ParlorNet: connect 300
type P
waittext dial again 900
snap di_error
dumptext di_error
key esc
waittext ParlorNet: connect 300
type S
waittext ParlorNet settings 300
type 6
wait 30
type 7
wait 30
arrows LL
type AT&F\r
wait 60
key ret
waittext ParlorNet: connect 300
type P
waittext Name: 900
snap di_both
dumptext di_both
oa Q
waittext ParlorNet: connect 1200
type S
waittext ParlorNet settings 300
type 8
wait 30
arrows LLLLLLLLLLLLLLLLLLLLLLLLLLLLLLLLLLL
wait 60
type ATD"parlornet.org:6501"\r
wait 300
snap di_atd_settings
dumptext di_atd_settings
key ret
waittext ParlorNet: connect 300
type P
waittext Name: 900
snap di_atd
dumptext di_atd
oa Q
waittext ParlorNet: connect 1200
exit
