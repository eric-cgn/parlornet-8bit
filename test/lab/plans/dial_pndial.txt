# The dialer through a Unix shell login (test/README.md, "Through a Unix shell"), with pndial installed as
# ATZ: no console step. P sends ATZ to the shell, which echoes it and runs pndial, which says OK; the dialer
# dials ATDT and the number, pndial says CONNECT and joins the line to the parlor with nc, and the program
# signs in. Open-Apple-Q: the parlor hangs up after BYE; OpenBSD's nc notices only when the program sends
# +++, then pndial says NO CARRIER and waits for the next dial, so P dials again, ATZ answered by pndial.
wait 120
caps
title 1800
waittext ParlorNet: connect 1200
type S
waittext ParlorNet settings 300
type 7
wait 30
arrows LLLLLLLLLLLLLLLLLLLLLLLLLLLLLLLLLLL
wait 120
type host.docker.internal:16501\r
wait 60
snap pn_settings
key ret
waittext ParlorNet: connect 300
type P
waittext Name: 900
snap pn_dialed
dumptext pn_dialed
type new\r
waittext want 300
type pia\r
waittext password 600
type Swordfish 1997\r
waittext again 600
type Swordfish 1997\r
wait 600
snap pn_lobby
oa Q
waittext ParlorNet: connect 1200
snap pn_hungup
type P
waittext Name: 900
snap pn_again
dumptext pn_again
type pia\r
waittext assword 600
type Swordfish 1997\r
wait 600
snap pn_lobby2
oa Q
waittext ParlorNet: connect 1200
type C
waittext Console 300
wait 60
type AT\r
wait 120
dumptext pn_console
snap pn_console
exit
