# Hanging up a modem that stays connected, on the WiFi-modem stand-in (port 16600): with STAY in the number
# it does not notice the parlor hanging up after BYE. The program waits a second and a half for NO CARRIER,
# then sends +++, waits for OK and sends ATH (modem.log shows "escape" and "hangup"). P then dials again.
wait 120
caps
title 1800
waittext ParlorNet: connect 1200
hold cfg_tutor 1 30
type S
waittext ParlorNet settings 300
type 7
wait 30
arrows LLLLLLLLLLLLLLLLLLLLLLLLLLLLLLLLLLL
wait 120
type STAY\r
wait 60
key ret
waittext ParlorNet: connect 300
type P
waittext Name: 900
type new\r
waittext want 300
type stan\r
waittext password 600
type Swordfish 1997\r
waittext again 600
type Swordfish 1997\r
wait 600
snap ds_lobby
oa Q
waittext ParlorNet: connect 1200
snap ds_hungup
type P
waittext Name: 900
snap ds_again
dumptext ds_again
oa Q
waittext ParlorNet: connect 1200
exit
